# Согласованный контракт UI и логики

**Принят человеком**: 2026-10-22  
**Решение**: контракт утверждён до реализации

## Вызовы и данные

| Назначение | Вызов | Запрос | Успех |
|---|---|---|---|
| Открыть интерфейс | `GET /` | — | HTML-страница |
| Проверить diff | `POST /api/reviews/validate` | `{"diff": string}` | `200 {"valid": true}` |
| Запустить ревью | `POST /api/reviews` | `{"diff": string}` | `200 {"comment": string}` |

## Порядок проверок и ошибки

1. Отсутствующий `diff`, нестроковый `diff` и пустая строка дают HTTP 422.
2. Любая строка длиннее 20 000 Unicode code points даёт HTTP 413, даже если она
   состоит только из пробелов.
3. Непустая строка длиной не более 20 000, содержащая только пробельные символы,
   даёт HTTP 422.
4. Допустимый diff не обрезается и не нормализуется.
5. Тело ошибки не является стабильной частью контракта: UI выбирает сообщение по
   HTTP-статусу.

## Границы между UI и логикой

- Preview никогда не вызывает `ReviewService` или LLM.
- Preview не выдаёт разрешение: настоящее ревью всегда валидирует diff повторно.
- UI-счётчик использует Unicode code points, но сервер остаётся источником истины.
- Изменение поля делает прежний результат preview неактуальным.
- Пока запрос выполняется, повторные запросы отключены.
- При ошибке введённый текст сохраняется.
- HTTP 404 от preview означает «предварительная проверка недоступна».
- Комментарий ревью отображается как текст, а не HTML.

## Согласованные сообщения UI

| Ситуация | Сообщение |
|---|---|
| HTTP 422 | Diff должен быть непустым текстом и содержать хотя бы один непробельный символ |
| HTTP 413 | Diff не должен превышать 20 000 символов |
| HTTP 404 preview | Предварительная проверка сейчас недоступна |
| Сеть или HTTP 5xx | Не удалось выполнить запрос. Попробуйте ещё раз |

## Не входит в изменение

Аутентификация, хранение истории, загрузка файла, редактирование секретов,
таймауты и обработка ошибок LLM, изменение MCP и новый формат ответа ревью.
