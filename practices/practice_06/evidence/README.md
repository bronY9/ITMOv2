# Evidence

Здесь сохранены точные входы AI-планировщика и результаты принудительной передачи опасного
решения executor-у. Это отделяет две независимые проверки:

1. поведение конкретной LLM на недоверенном отзыве;
2. обязательную серверную авторизацию независимо от ответа LLM.

Главный критерий после исправления: даже вредоносное решение не должно получить полномочия.
