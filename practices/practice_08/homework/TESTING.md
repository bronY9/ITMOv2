# Проверки и соответствие критериям

## Фактические проверки

- Локальная сборка TypeScript/Vite: `evidence/build.txt`.
- 18 проверок Vitest/RTL/MSW: `evidence/component-tests.txt`.
- Контрольная поломка: убран заголовок ошибки, тест API 500 ожидаемо
  завершился с кодом 1. Код восстановлен: `evidence/mutation-check.txt`.
- Настоящий API с Ollama `qwen3.5:4b` вернул непустой `comment`:
  `evidence/real-api-response.json`.
- В Safari вручную проверено: вставка примера, отправка через ⌘ + Enter,
  недоступные повторные действия при загрузке, настоящий ответ в UI.
  Использован только учебный diff average.py.
- Регрессия сервиса: 19 тестов практики 5 прошли.

Chromium из ограниченного процесса Codex/macOS остановился до страницы:
`bootstrap_check_in ... Permission denied`. WebKit также не запустился
в этой среде. Это не результаты проверки интерфейса. Браузерный набор
подготовлен для GitHub Actions на Linux, но ещё не проверен. Публикацию
новой ветки отклонила автоматическая проверка: пользователь запросил
локальную работу. После отдельного разрешения можно отправить ветку,
запустить CI и сохранить скриншоты. Успешный прогон пока не заявляется.

## Действия и ожидаемые результаты

| Проверка | Поведение |
|---|---|
| Исходное состояние | Подпись, обязательность поля, счётчик, пустой результат |
| Пример | Заполнение формы и перевод фокуса в поле |
| Помощь | Диалог, закрытие кнопкой/Escape, восстановление фокуса |
| Валидация | Пустота, пробелы, 20 001 символ → ошибка без HTTP |
| Граница | Ровно 20 000 букв или emoji → запрос с исходной строкой |
| Полный сценарий | Ввод → POST с точным diff → видимый Markdown-комментарий |
| Задержка | Двойной клик, submit, Ctrl+Enter → один запрос, загрузка |
| Ошибка | API 500 → сообщение, исходный текст сохранён, повтор успешен |
| Ответы | Сетевая ошибка, HTTP 413/422, неверный контракт |
| Пустой ответ | Пустой/пробельный comment → отдельное состояние с повтором |
| Браузер | Клавиатура, фокус, 390 px, длинный код, axe, прототип |

Подменяются HTTP-ответы, а не `requestReview`, компоненты или React hooks.
Успешные фикстуры соответствуют реальному API: `{"comment":"..."}`.
Настоящая демонстрация в Safari не использовала подмены.

ревьювер по фактическому состоянию на сдаче.

| № | Баллы | Подтверждение |

| 2 | 0,5 | Компоненты Material UI в App/ReviewResult |

| 4 | 1 | UI → существующий API → настоящая Ollama |

Для тестовых баллов все клиентские тесты должны проходить. Локальная
невозможность запуска браузера не выдаётся за успешный прогон: перед
сдачей нужен подтверждённый CI или запуск в обычном терминале.
