коммит `85e5493`: сборка, 18 клиентских проверок и 8 браузерных сценариев.

этого запуска. Файлы приложения и клиентских тестов после этого прогона
при согласовании ветки с main не менялись.

После синхронизации с main добавлена также отдельная CI-проверка импорта
backend и его 19 регрессионных тестов. Статус новых запусков:
[проверки ветки](https://github.com/bronY9/ITMOv2/actions?query=branch%3Apractice_08).

## Действия и ожидаемые результаты

| Проверка | Поведение |
|---|---|
| Исходное состояние | Подпись, обязательность поля, счётчик, пустой результат |
| Пример | Заполнение формы и перевод фокуса в поле |
| Помощь | Диалог, закрытие кнопкой/Escape, восстановление фокуса |
| Валидация | Пустота, пробелы, 20 001 символ → ошибка без HTTP |
| Граница | Ровно 20 000 букв или emoji → запрос с исходной строкой |
| Полный сценарий | Ввод → POST с точным diff → видимый Markdown-комментарий |
| Задержка | Двойной клик, submit, Ctrl+Enter → один запрос, загрузка |
| Ошибка | API 500 → сообщение, исходный текст сохранён, повтор успешен |
| Ответы | Сетевая ошибка, HTTP 413/422, неверный контракт |
| Пустой ответ | Пустой/пробельный comment → отдельное состояние с повтором |
| Браузер | Клавиатура, фокус, 390 px, длинный код, axe, прототип |

Подменяются HTTP-ответы, а не `requestReview`, компоненты или React hooks.
Успешные фикстуры соответствуют реальному API: `{"comment":"..."}`.
Настоящая демонстрация в Safari не использовала подмены.
