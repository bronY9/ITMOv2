# Использование AI

Инструмент реализации и макета — Codex. Документация Material UI проверялась
через Context7; типы установленной MSW — в исходниках пакета. Экспорт
прототипа сделан HTML/CSS/JavaScript, без Figma или v0.

Запрос пользователя: «реши 8 лабораторную работу используя тз из локального
файла в ITMOv2 practice_08». Дополнительное ограничение — выполнить все
критерии, сохранив реализацию понятной для самостоятельной защиты.

## Примеры запросов для повторения процесса

Это воспроизводимые формулировки, а не выдуманная стенограмма отдельных
обращений к другим моделям.

**Макет:** «Создай самостоятельный интерактивный HTML-прототип интерфейса
существующего сервиса ревью diff. Русский язык, две карточки: ввод и
результат. Покажи исходное состояние, ввод, загрузку, успех, пустой ответ и
ошибку. Общие цвета, отступы 8 px, мобильная версия, диалог git diff».

**Интерфейс:** «Перенеси прототип в React + TypeScript. Переиспользуй
Material UI Button, TextField, Card, Dialog, Alert и Skeleton, общую тему.
Подключи POST /api/reviews, сохраняй точный diff при ошибке, проверяй
пустую строку и лимит 20 000, не допускай повтор при ожидании».

**Тесты:** «Реализуй проверки видимого поведения формы: валидация, диалог,
клавиатура, fetch с HTTP-подменой MSW, успех/пустой ответ/задержка/ошибка.
Повторные действия при задержке должны дать один запрос. Проверь тест
контрольной поломкой».

## Вклад и исправления

Codex создал сценарий, ранний прототип, React-компоненты, тему, адаптер
Ollama, тесты, CI и документацию. Прототип сохранён отдельным коммитом до
реализации интерфейса.

После проверки внесены конкретные исправления:

- В MUI 9 свойства Stack/Typography перенесены в `sx`: старый синтаксис
  дал ошибки TypeScript и предупреждения React.
- В MSW 3 использовано `onUnhandledFrame` вместо `onUnhandledRequest`.
  Необработанные запросы в тестах считаются ошибками.
- Счётчик использует Unicode code points, как Python `len`: emoji не
  расходует два символа лимита. Проверены обе границы.
- Блокировка через ref дополняет `disabled`: повтор может возникнуть до
  обновления DOM.
- В браузерном тесте учтена кнопка «Вставить пример» между помощью и
  полем. Порядок фокуса нельзя предполагать.
- Подсказка и действие Ctrl/⌘ + Enter добавлены в прототип для соответствия UI.
- Контрольная поломка убрала заголовок ошибки из компонента. Тест API 500
  упал; затем компонент восстановлен и тесты запущены заново.

Перед защитой студенту нужно самому пройти сценарий и понимать решения.
Этот документ не утверждает, что студент уже выполнил такую проверку.
